# Current → Target Gap Model

## Current strengths to preserve

The existing Agentic Discipline already has strong foundations around:

- protected engineering intent;
- requirement traceability;
- deterministic verification;
- evidence-led completion;
- risk-aware quality gates;
- integrity checks;
- architecture/security review;
- multi-tool installation surfaces;
- stack-aware project detection;
- adoption into existing repositories;
- workflows that prevent an agent from simply saying "done".

These are not to be rewritten without need.

## Major gaps for 2.0

### Gap A — Project understanding is not yet a first-class persistent model
Need:
- measurable repository discovery;
- understanding coverage;
- provenance;
- conflict tracking;
- confidence/authority distinction.

### Gap B — Knowledge is mostly artifact-oriented
Need:
- persistent knowledge platform;
- canonical/historical separation;
- typed relationships;
- versioned entities;
- query layer.

### Gap C — Planning is not yet an autonomous readiness system
Need:
- plan completeness audit;
- ambiguity/gap classification;
- ask-last resolver;
- readiness gate.

### Gap D — Execution state is not durable enough
Need:
- task contracts;
- execution state machine;
- checkpoints;
- resumability;
- handoff packages.

### Gap E — No true shared multi-agent coordination plane
Need:
- agent registration;
- leases;
- workspaces;
- capability-aware task claiming;
- parallel safety;
- integration gates.

### Gap F — Context is not yet managed as a measurable resource
Need:
- context audit;
- context budgets;
- minimum-sufficient context builder;
- context-low behavior.

### Gap G — Knowledge drift requires continuous reconciliation
Need:
- external-change detection;
- impact analysis;
- evidence invalidation;
- semantic garbage collection;
- lifecycle management.

### Gap H — Human visibility is scattered
Need:
- project console;
- health metrics;
- blockers;
- agent activity;
- stale knowledge;
- human decision queue.

### Gap I — Knowledge writes need stronger transactional rules
Need:
- changesets;
- optimistic concurrency;
- invariant checks;
- version numbers;
- rollback.

### Gap J — Research influence needs provenance
Need:
- influence ledger for external ideas;
- no code-copy assumption;
- explicit first-party re-expression.
