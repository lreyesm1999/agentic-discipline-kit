# Research Influence Ledger

## Purpose

Study external tools without turning Agentic Discipline into copied code.

## Record schema

```json
{
  "sourceId": "example-project",
  "sourceType": "github",
  "sourceUrl": "...",
  "revision": "...",
  "reviewedAt": "...",
  "conceptsStudied": [
    "lease coordination",
    "graph-first discovery"
  ],
  "acceptedIdeas": [
    "lease expiry semantics"
  ],
  "rejectedIdeas": [
    "central model router"
  ],
  "firstPartyImplementationNotes": "...",
  "codeImported": false,
  "licenseReviewRequired": false
}
```

## Required rules

- Ideas may inspire architecture.
- External code is not imported by default.
- External prompts/skills are not redistributed.
- Every important adopted concept must be re-expressed in Agentic Discipline terminology and architecture.
- Track the exact revision studied so later comparisons are reproducible.

## Initial influence categories to study

From SkillMesh-style patterns:
- graph-first discovery;
- context audit;
- handoff discipline;
- transactionally managed installation;
- lifecycle dispositions;
- project overrides;
- vertical slices;
- research source tracking.

These are ideas to reinterpret, not code to copy.
