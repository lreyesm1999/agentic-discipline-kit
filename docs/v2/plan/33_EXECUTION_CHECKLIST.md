# Execution Checklist

## Before coding any phase
- [ ] Current capability equivalent checked.
- [ ] Reuse opportunity documented.
- [ ] Input/output contract defined.
- [ ] Failure states defined.
- [ ] Acceptance criteria defined.
- [ ] Required evidence defined.
- [ ] Rollback considered.
- [ ] Security implications considered.
- [ ] Migration impact considered.

## Before marking task complete
- [ ] Required tests passed.
- [ ] Evidence attached.
- [ ] Evidence not stale.
- [ ] Knowledge updated.
- [ ] Checkpoint written.
- [ ] No unresolved lifecycle cleanup.
- [ ] Integration gate passed if needed.

## Before merging
- [ ] Branch refreshed.
- [ ] Assumptions still valid.
- [ ] Cross-task tests passed.
- [ ] Protected contracts unchanged or approved.
- [ ] Knowledge invariants pass.
- [ ] Reconciliation complete.

## Before release
- [ ] Migration tested.
- [ ] Rollback tested.
- [ ] Failure injection relevant to release completed.
- [ ] Security review complete.
- [ ] Project console/CLI reports consistent state.
- [ ] Release evidence recorded.
