# Roadmap

## Near term

- native acceptance code generators for TypeScript, Python, and .NET;
- structured parsers for common coverage and mutation report formats;
- dependency-graph-based affected test selection;
- SARIF output for integrity and policy findings;
- native SARIF publication for all deterministic reports.

## Later

- Go, Java, Rust, and mobile adapters;
- CI-native evidence attestation;
- policy packs by risk domain;
- machine-readable skill manifest.
