# Governance

Agentic Discipline Kit uses maintainer-led governance.

## Roles

**Contributors** propose changes through issues and pull requests.

**Maintainers** review changes, manage releases, evolve policies, and protect the framework's core
contracts.

## Decision principles

Changes are evaluated on:

1. correctness;
2. evidence quality;
3. security;
4. portability;
5. clarity;
6. backward compatibility;
7. maintenance cost.

Changes to policy semantics, protected-contract behavior, schemas, and release criteria require
explicit maintainer review.

## Releases

The project follows Semantic Versioning. Breaking contract changes require a major version.
